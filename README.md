
 Laboratorio de Patrones de Diseño - Biblioteca

Sistema de reservas de salas de biblioteca desarrollado en Java 17.

Patrones de diseño
- Builder
- Strategy
- Facade
- Observer
- State

 Objetivo
Implementar un prototipo de consola que permita gestionar reservas de salas de biblioteca mediante patrones de diseño.

Tecnologías
- Java 17 o superior
- Git y GitHub
